# Code of Conduct

## Our standard

Project discussions should be respectful, specific, and focused on improving
the software. Criticism of code and technical decisions is welcome when it is
constructive. Harassment, personal attacks, discriminatory language, threats,
spam, and repeated disruption are not acceptable.

The maintainers decide the project's scope, design, release timing, and whether
a contribution is accepted. Disagreement is allowed; continued pressure after
a decision has been explained is not.

## Scope

This standard applies to the repository, issue tracker, pull requests, and
official Intermynd Instruments project discussions.

## Enforcement

Maintainers may edit or remove comments, close or lock discussions, reject
contributions, or restrict participation when necessary.
